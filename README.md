# GuitarApp – prototipo

Prototipo web di un'app per esercitarsi con la chitarra: scale e modi sul manico, accordi, progressioni,
orecchio, accordatore, lettore dei brani con riconoscimento degli accordi, pennata, tablature e canto.

Tutto gira nel browser: i brani caricati restano sul dispositivo e non vengono inviati a nessun server.

Componenti di terze parti:
- alphaTab 1.9.0 (MPL-2.0), caricato da jsDelivr;
- Bravura (SIL Open Font License), incorporato nella pagina;
- signalsmith-stretch 1.3.2 (MIT), caricato da jsDelivr.
